Squipi · Apple silicon · macOS 26+

1. Unzip the download.
2. Double-click “Install Squipi.command”. Or drag it into Terminal and press Return.
3. Squipi opens. Its installed app is in your home Applications folder.
4. Keep its Dock icon: right-click → Options → Keep in Dock.

You can also drag Squipi.app into Applications yourself and open it.
Attach a file in Chat, type your instruction, then Send. Attaching alone never starts analysis.

In Me choose Ollama (installed locally with a downloaded model) or configure Nebius.
Python/data tools set up automatically when first needed, using a bundled runtime manager;
the first setup needs the internet. Local model downloads and Nebius credentials are separate.
Me also contains colours, clothing, accessories, language and the optional NeMo runner.

The “local-test” download is a development build, not a notarized public release.
Do not disable Gatekeeper. A public distribution needs Developer ID signing and Apple notarization.
This is not a Mac App Store or TestFlight build.
